# Food Delivery Website

A restaurant-first food ordering website concept intended to connect customers directly with restaurants, reducing reliance on third-party delivery marketplaces.

## Overview

The project explores a direct ordering experience with restaurant information and food discovery. The current implementation is a browser-based website built with HTML and CSS.

## Run locally

```bash
git clone https://github.com/Imran-Munge/food-delivery-website.git
cd food-delivery-website
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

## Development

The project currently uses static web assets. Review the existing HTML, CSS, and linked assets before extending the ordering flow or integrating a backend. Do not collect payment or customer information until appropriate secure services are implemented.
